# Support

Use this repository for Homebrew tap problems:

- `brew install gethasp/tap/hasp` fails
- `brew upgrade hasp` resolves an old formula
- formula checksums or download URLs are wrong
- installed files are missing from the Homebrew package

Use the product repository for HASP behavior, feature requests, or runtime bugs:

<https://github.com/gethasp/hasp/issues>

Before opening a tap issue, collect:

```bash
brew --version
brew config
brew doctor
brew info gethasp/tap/hasp
```

Do not paste secrets, environment files, vault contents, tokens, or private
logs into a public issue.
