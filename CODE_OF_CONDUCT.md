# Code of Conduct

This project uses a simple standard for public participation: be respectful,
constructive, and focused on improving HASP installation through Homebrew.

## Expected Behavior

- Use welcoming and professional language.
- Assume good intent, but respond to impact when something causes harm.
- Keep feedback specific, actionable, and relevant to the tap.
- Respect maintainer decisions about scope and repository boundaries.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Discriminatory language or imagery.
- Publishing private information without permission.
- Posting secrets, exploit details, or private logs in public issues.
- Repeated off-topic comments after maintainers redirect the discussion.

## Enforcement

Maintainers may edit, hide, lock, or delete comments and issues that violate
this code of conduct. Maintainers may also block accounts from participation
when needed to protect the project and its users.

Security reports should follow [SECURITY.md](SECURITY.md), not public issues.
